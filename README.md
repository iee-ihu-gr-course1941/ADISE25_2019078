1. Γενική Περιγραφή του Project
  Το παρόν project υλοποιήθηκε στο πλαίσιο του μαθήματος «Ανάπτυξη Διαδικτυακών Συστημάτων και Εφαρμογών» και αφορά την ανάπτυξη μιας διαδικτυακής εφαρμογής για το παραδοσιακό ελληνικό παιχνίδι καρτών Ξερή.
  Στόχος του έργου είναι η εφαρμογή στην πράξη των εννοιών που παρουσιάστηκαν στο μάθημα, όπως ο σχεδιασμός Web API, η διαχείριση κατάστασης στον server, η χρήση βάσης δεδομένων για μόνιμη αποθήκευση δεδομένων
  και η επικοινωνία client–server μέσω JSON. Η εφαρμογή υποστηρίζει παιχνίδι δύο παικτών (Human–Human), με βασικό γραφικό περιβάλλον μέσω web browser. Όλη η επιχειρησιακή λογική του παιχνιδιού υλοποιείται
  αποκλειστικά στην πλευρά του server, ενώ ο client χρησιμοποιείται μόνο για την απεικόνιση της κατάστασης και την αποστολή αιτημάτων.

2. Αρχιτεκτονική Συστήματος
 Η αρχιτεκτονική της εφαρμογής βασίζεται στο πρότυπο Client–Server, με σαφή διαχωρισμό αρμοδιοτήτων μεταξύ των δύο πλευρών. Ο client υλοποιείται με HTML, CSS και JavaScript και επικοινωνεί με τον server μέσω
  AJAX κλήσεων. Ο client δεν διατηρεί κρίσιμη πληροφορία για την κατάσταση του παιχνιδιού και δεν εφαρμόζει κανόνες παιχνιδιού. Αντίθετα, ο server αποτελεί το μοναδικό σημείο ελέγχου της ροής του παιχνιδιού. Ο
  server υλοποιείται σε PHP και παρέχει ένα σύνολο από Web API endpoints, τα οποία χειρίζονται:
                              τη σύνδεση χρηστών,
                              τη δημιουργία και διαχείριση παιχνιδιών,
                              την εκτέλεση κινήσεων,
                              τον έλεγχο κανόνων,
                              τη διαχείριση παρουσίας χρηστών,
                              την ανταλλαγή μηνυμάτων (chat).
Η επικοινωνία client–server πραγματοποιείται αποκλειστικά με ανταλλαγή δεδομένων σε μορφή JSON, όπως απαιτείται από το μάθημα.

3. Διαχείριση Χρηστών και Authentication
    Η εφαρμογή υλοποιεί μηχανισμό αρχικοποίησης σύνδεσης χρηστών χωρίς χρήση κωδικού πρόσβασης. Η επιλογή αυτή ακολουθεί τις οδηγίες του μαθήματος και είναι κατάλληλη για εκπαιδευτικό περιβάλλον. Κατά τη σύνδεση,
     ο χρήστης δηλώνει ένα όνομα χρήστη (username). Το σύστημα ελέγχει αν υπάρχει ήδη χρήστης με το συγκεκριμένο όνομα στη βάση δεδομένων. Αν υπάρχει, επιστρέφονται τα στοιχεία του. Αν όχι, δημιουργείται νέα
     εγγραφή χρήστη.
    Σε κάθε χρήστη αντιστοιχίζεται:
        ένα μοναδικό αναγνωριστικό player_id,
        ένα μοναδικό διακριτικό πρόσβασης (token).
Το token χρησιμοποιείται σε όλες τις επόμενες κλήσεις προς το Web API και αποστέλλεται μέσω HTTP header τύπου Authorization: Bearer. Με τον τρόπο αυτό, ο server μπορεί να ταυτοποιεί αξιόπιστα τον χρήστη και να
ελέγχει την πρόσβασή του σε προστατευμένες λειτουργίες του συστήματος.

4. Δημιουργία και Συμμετοχή σε Παιχνίδι
    Η εφαρμογή επιτρέπει τη δημιουργία νέων παιχνιδιών από έναν παίκτη, καθώς και τη συμμετοχή δεύτερου παίκτη σε παιχνίδια που βρίσκονται σε κατάσταση αναμονής. Ο πρώτος παίκτης δημιουργεί το παιχνίδι και
    αρχικοποιεί τις βασικές ρυθμίσεις, όπως:
                 χρόνος ανά κίνηση,
                 στόχος σκορ για τη νίκη.
Το παιχνίδι παραμένει σε κατάσταση waiting έως ότου συνδεθεί δεύτερος παίκτης. Με την είσοδο του δεύτερου παίκτη, το παιχνίδι μεταβαίνει σε κατάσταση active και πραγματοποιείται το αρχικό μοίρασμα των φύλλων.
Όλες οι παραπάνω πληροφορίες αποθηκεύονται στη βάση δεδομένων, ώστε η κατάσταση του παιχνιδιού να είναι μόνιμα διαθέσιμη.

5. Διαχείριση Κατάστασης Παιχνιδιού
  Η κατάσταση του παιχνιδιού (game state) διατηρείται εξ ολοκλήρου στον server και αποθηκεύεται σε μορφή JSON στη βάση δεδομένων. Η κατάσταση αυτή περιλαμβάνει:
        τη σειρά παιξιάς,
        τα φύλλα των παικτών,
        τα φύλλα στο τραπέζι,
        το υπόλοιπο της τράπουλας,
        το σκορ κάθε παίκτη,
        τον χρόνο έναρξης της τρέχουσας κίνησης,
        την κατάσταση λήξης ή ολοκλήρωσης του παιχνιδιού.
Ο client ανακτά την κατάσταση αυτή μέσω ειδικού endpoint και τη χρησιμοποιεί αποκλειστικά για εμφάνιση. Δεν επιτρέπεται στον client να τροποποιεί απευθείας το game state.

6. Εκτέλεση Κινήσεων και Έλεγχος Κανόνων
    Η εκτέλεση κινήσεων πραγματοποιείται μέσω ειδικού endpoint του Web API. Κάθε κίνηση περνά από τον server, ο οποίος:
         ελέγχει ότι ο παίκτης έχει σειρά,
         επαληθεύει ότι το φύλλο που παίζεται ανήκει στο χέρι του παίκτη,
         εφαρμόζει τους κανόνες της Ξερής,
         ενημερώνει το σκορ και την κατάσταση του τραπεζιού.
Με τον τρόπο αυτό αποτρέπεται οποιαδήποτε μη έγκυρη ή κακόβουλη ενέργεια από την πλευρά του client.

7. Αναγνώριση Σειράς Παιξιάς και Deadlock
  Η σειρά παιξιάς καθορίζεται και ελέγχεται αποκλειστικά στον server. Οποιαδήποτε προσπάθεια εκτέλεσης κίνησης εκτός σειράς απορρίπτεται. Το σύστημα αναγνωρίζει επίσης καταστάσεις τερματισμού γύρου ή παιχνιδιού,
  καθώς και περιπτώσεις όπου δεν υπάρχουν διαθέσιμες κινήσεις. Σε τέτοιες περιπτώσεις, η κατάσταση ενημερώνεται κατάλληλα και αποθηκεύεται στη βάση δεδομένων.

9. Διαχείριση Παρουσίας Χρηστών
  Η εφαρμογή περιλαμβάνει μηχανισμό παρακολούθησης της παρουσίας των παικτών στο παιχνίδι. Ο client αποστέλλει περιοδικά σήμα παρουσίας στον server, δηλώνοντας ότι ο χρήστης παραμένει ενεργός.
  Η πληροφορία αυτή χρησιμοποιείται για:
      την εμφάνιση της κατάστασης του αντιπάλου,
      την ανίχνευση αποσύνδεσης,
      την αποφυγή προβλημάτων στη ροή του παιχνιδιού.
      Σε περίπτωση αποχώρησης, ο χρήστης δηλώνει ρητά ότι δεν βρίσκεται πλέον στο παιχνίδι, επιτρέποντας στο σύστημα να ενημερώσει σωστά την κατάσταση.

9. Σύστημα Επικοινωνίας (Chat)
    Το σύστημα υποστηρίζει ανταλλαγή μηνυμάτων μεταξύ των παικτών μέσω Web API. Όλα τα μηνύματα αποθηκεύονται στη βάση δεδομένων και ανακτώνται δυναμικά από τον client.  Υποστηρίζεται επίσης ένδειξη
    πληκτρολόγησης, η οποία βελτιώνει την εμπειρία χρήστη και προσδίδει αίσθηση σύγχρονης επικοινωνίας.

11. Βάση Δεδομένων
  Η εφαρμογή χρησιμοποιεί βάση δεδομένων MySQL. Όλες οι κρίσιμες πληροφορίες αποθηκεύονται μόνιμα, συμπεριλαμβανομένων:
      χρηστών,
      παιχνιδιών,
      κινήσεων,
      μηνυμάτων,
      παρουσίας χρηστών.
Το πλήρες σχήμα της βάσης περιλαμβάνεται στο αρχείο xeri_db.sql, το οποίο είναι διαθέσιμο στο αποθετήριο του project.

11. Τεχνολογίες που Χρησιμοποιήθηκαν

Η υλοποίηση του project βασίστηκε στις ακόλουθες τεχνολογίες: PHP, MySQL, HTML, CSS, JavaScript, AJAX (jQuery) και JSON. Για την ανάπτυξη και δοκιμή χρησιμοποιήθηκε Apache μέσω XAMPP, ενώ η διαχείριση του κώδικα
πραγματοποιήθηκε μέσω GitHub.

13. Συμπεράσματα

Το project καλύπτει πλήρως τις απαιτήσεις του μαθήματος και αποτελεί ολοκληρωμένο παράδειγμα ανάπτυξης διαδικτυακού συστήματος βασισμένου σε Web API. Η υλοποίηση διασφαλίζει την ορθότητα της λογικής παιχνιδιού, 
την ασφάλεια των κλήσεων και τη μόνιμη αποθήκευση της κατάστασης.
